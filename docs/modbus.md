# CH579M Modbus RTU 从机协议文档

- 工程：CH579_USB_Host_HID_pro
- MCU：CH579M（ARM Cortex-M0）
- 更新：2026-08-11
- 硬件：UART3（TXD3=PA5 / RXD3=PA4），PA6=RE/DE 方向控制（RS485），可 TTL 直连测试

## 1. 功能概述

CH579M 作为 **Modbus RTU 从机**，将 USB 键盘输入的 ASCII 字符按顺序存入
保持寄存器 40001~40128，供主站（PLC / 组态软件 / 上位机）通过 0x03 读取。
从机地址与波特率可通过 0x06 写配置寄存器在线修改，并存入 DataFlash 掉电保存。

## 2. 串口参数

| 参数 | 值 |
| ---- | ---- |
| 波特率 | 9600 / 19200 / 38400 / 57600 / 115200（默认 9600，可配置） |
| 数据位 | 8 |
| 校验 | 无（None） |
| 停止位 | 1 |
| 帧格式 | RTU |
| 帧间隔 | ≥ 3.5 字符时间（9600 下约 3.65ms） |

## 3. 寄存器映射

| Modbus 地址 | 寄存器号 | 方向 | 内容 |
| ---- | ---- | ---- | ---- |
| 0x0000 ~ 0x007F | 40001 ~ 40128 | 只读 | 键盘 ASCII 数据区，见第 4 节 |
| 0x0080 | 40129 | 读/写 | 从机地址配置（1~247） |
| 0x0081 | 40130 | 读/写 | 波特率索引配置（0~4） |

### 3.1 数据区（40001~40128）

- 每个寄存器 16 位：**低字节 = ASCII 码，高字节 = 0**
- 无字符的寄存器值为 0
- 读 40001 起始的 N 个寄存器，返回顺序即输入顺序
- **只读**：0x06 写入本区返回异常码 0x02

### 3.2 配置区（40129~40130）

| 地址 | 含义 | 合法值 |
| ---- | ---- | ---- |
| 0x0080 | 从机地址 | 1 ~ 247 |
| 0x0081 | 波特率索引 | 0=9600, 1=19200, 2=38400, 3=57600, 4=115200 |

- 0x03 读取配置区时数量必须为 1（数量 >1 返回异常码 0x02）
- 0x06 写入后立即生效并保存到 DataFlash（掉电不丢失）
- 写波特率**立即生效**：当前会话会掉线，主站需切换波特率重新连接

## 4. 数据写入规则（键盘操作）

| 键 | 行为 |
| ---- | ---- |
| 可打印字符（0x20~0x7E，含空格） | 追加到寄存器组当前位 |
| Enter（主键盘 / 小键盘） | 立即提交：余段清零，写入位复位 |
| Backspace | 回退一位并清零该寄存器 |
| 暂停输入 500ms | 空闲超时自动提交 |
| 其他键（F1、Esc、方向键等） | 忽略，不写入 |

字母大小写随 CapsLock/Shift 变化，数字/标点随 Shift 出符号。

## 5. 功能码

| 功能码 | 名称 | 支持 |
| ---- | ---- | ---- |
| 0x03 | 读保持寄存器 | ✅ |
| 0x06 | 写单个保持寄存器（仅配置区） | ✅ |
| 其他 | — | ❌ 异常码 0x01 |

### 5.1 读保持寄存器（0x03）

请求帧（8 字节）：

```
[从机地址][0x03][起始地址高][起始地址低][数量高][数量低][CRC低][CRC高]
```

应答帧（正常）：

```
[从机地址][0x03][字节数 = 数量×2][寄存器高][寄存器低]...[CRC低][CRC高]
```

限制：
- 单次数量 ≤ 125（超出需分段读取，如 40001~40125 与 40126~40128）
- 数据区越界（起始地址 + 数量 > 128）→ 异常码 0x02

### 5.2 写单个保持寄存器（0x06，仅配置区）

请求帧（8 字节）：

```
[从机地址][0x06][寄存器地址高][寄存器地址低][值高][值低][CRC低][CRC高]
```

应答帧：**原样回显请求帧**（标准 0x06 行为）。

限制：
- 地址 0x0080：值必须在 1~247，否则异常码 0x03
- 地址 0x0081：值必须在 0~4，否则异常码 0x03
- 其他地址（含数据区）→ 异常码 0x02

## 6. 异常码

| 异常码 | 含义 | 触发条件 |
| ---- | ---- | ---- |
| 0x01 | 非法功能 | 功能码不是 0x03/0x06 |
| 0x02 | 非法数据地址或数量 | 数量=0、>125、地址越界、0x06 写非配置地址、0x03 读配置区数量≠1 |
| 0x03 | 非法数据值 | 0x06 写配置区的值超出合法范围 |

异常应答帧：

```
[从机地址][功能码|0x80][异常码][CRC低][CRC高]
```

## 7. 帧格式与 CRC16

- RTU 帧 = 地址(1B) + 功能码(1B) + 数据(nB) + CRC16(2B)
- CRC16：Poly 0xA001，初值 0xFFFF，逐位运算；**低字节在前发送**
- 帧边界：3.5 字符空闲时间判定
- 地址不匹配（含广播地址 0）或 CRC 错误 → **不应答**（静默丢弃）

## 8. 帧示例

### 8.1 读 40001 起 5 个寄存器

发送：

```
01 03 00 00 00 05 85 C9
```

应答（键盘已输入 "ABC"）：

```
01 03 0A 00 41 00 42 00 43 00 00 00 00 6A E0
```

| 字段 | 值 | 说明 |
| ---- | ---- | ---- |
| 01 | 从机地址 | addr=1 |
| 03 | 功能码 | 读保持寄存器 |
| 0A | 字节数 | 5 寄存器 × 2 = 10 |
| 00 41 | 寄存器 40001 | 'A' |
| 00 42 | 寄存器 40002 | 'B' |
| 00 43 | 寄存器 40003 | 'C' |
| 00 00 00 00 | 寄存器 40004~5 | 未输入，为 0 |

### 8.2 修改从机地址为 2

发送：

```
01 06 00 80 00 02 09 E3
```

应答：原样回显 `01 06 00 80 00 02 09 E3`。此后主站必须以地址 2 通信，
且断电重启后地址仍为 2。

### 8.3 修改波特率为 19200

发送：

```
01 06 00 81 00 01 18 22
```

应答：回显后**立即切换到 19200**，主站需改波特率重连。

### 8.4 非法值示例

| 发送 | 应答 | 说明 |
| ---- | ---- | ---- |
| `01 06 00 80 00 00 88 22` | `01 86 03 xx xx` | 地址=0 非法（异常 0x03） |
| `01 06 00 80 00 FA 08 61` | `01 86 03 xx xx` | 地址=250 非法 |
| `01 06 00 81 00 05 19 E1` | `01 86 03 xx xx` | 波特率索引=5 非法 |
| `01 06 00 01 00 41 18 3A` | `01 86 02 xx xx` | 写数据区被拒绝（异常 0x02） |
| `01 04 00 00 00 05 30 09` | `01 84 01 82 C0` | 功能码 0x04 不支持（异常 0x01） |
| `02 03 00 00 00 05 85 FA` | （无应答） | 地址不匹配 |

## 9. 配置掉电保存

- 参数存储于芯片内置 DataFlash（地址 0x3E800，512B/扇区）
- 结构：magic(0xA5A5A5A5) + addr + baud + CRC16 校验，共 8 字节
- 上电自动加载；magic/CRC 无效或值越界时回退默认（addr=1, baud=0）
- 0x06 写入后立即保存；保存失败仅 UART1 打印 `cfg save fail`（内存值仍生效）

## 10. 硬件接线

### RS485 模式

| CH579M | RS485 收发器 |
| ---- | ---- |
| PA5 (TXD3) | DI |
| PA4 (RXD3) | RO |
| PA6 (RE/DE) | 经 1k 电阻接 RE/DE（高=发送，低=接收） |

### TTL 直连测试（无需 RS485）

| CH579M | USB-TTL 模块（3.3V） |
| ---- | ---- |
| PA5 (TXD3) | RX |
| PA4 (RXD3) | TX |
| GND | GND |
| PA6 | 悬空 |

## 11. 故障排查

| 现象 | 排查 |
| ---- | ---- |
| 无任何应答 | 检查地址、波特率、接线共地、CRC |
| 只读得到 0 | 未输入字符或帧已提交后未重新输入 |
| 改配置后失联 | 波特率已改，需切波特率重连；地址已改，需用新地址 |
| 上电打印 `WDOG reset` | 上次看门狗复位（异常重启），检查供电稳定性 |
| 上电打印 `reset: normal` | 正常 |
